# Полиглот · английский по методу Дмитрия Петрова

Личный тренажёр английского для Азамата и жены. Работает офлайн, ставится на
домашний экран iPhone как обычное приложение, прогресс у каждого свой.

---

## Что внутри

**16 уроков.** Структура повторяет телекурс «Полиглот. Выучим английский
за 16 часов» (телеканал «Культура»): от базовой таблицы глагола до Perfect,
пассива и фразовых глаголов. У каждого урока — конспект, словарь, тренажёр
и экзамен.

**Тренажёр фраз.** Ядро метода. Приложение показывает русскую фразу, вы
собираете английскую из плиток (или печатаете — переключается в настройках).
Фразы **генерируются на лету** грамматическим движком: 56 глаголов × 6 лиц ×
3 времени × 3 формы × дополнения. Заучить набор невозможно — приходится
каждый раз проходить по таблице. Именно это Петров и называет «довести
до автоматизма».

**Карточки слов.** 483 слова, интервальное повторение по алгоритму SM-2
(как в Anki). Не больше 10 новых слов в день, остальное — повторы по графику.

**Разблокировка по экзамену.** Следующий урок открывается, когда сдан
экзамен текущего на 80%. Это не даёт проскочить вперёд, не закрепив таблицу.

**Два профиля.** Азамат и жена. Отдельный прогресс, отдельные карточки,
отдельные серии дней. Русские подсказки учитывают род: «я делал» / «я делала».

**Озвучка.** Каждая фраза и каждое слово произносятся встроенным синтезом
речи iOS. Ничего скачивать не нужно.

## Как поставить на iPhone

### Вариант А — правильный (рекомендую)

Нужен бесплатный хостинг с HTTPS, иначе iOS не даст поставить иконку
на экран и не включит офлайн-режим.

1. Создайте репозиторий на GitHub и залейте туда содержимое этой папки
   (кроме `test*.js` и `node_modules` — они не нужны).
2. Settings → Pages → Source: `main`, папка `/root`. Сохраните.
3. Через минуту сайт будет по адресу `https://ваш-логин.github.io/имя-репо/`.
4. Откройте адрес в **Safari** на iPhone → кнопка «Поделиться» →
   **«На экран "Домой"»**.
5. Готово. Иконка «Полиглот», запуск на весь экран, работает в самолёте.

Жене — просто отправьте ту же ссылку, она проделает то же самое на своём
телефоне. Прогресс у каждой копии свой.

### Вариант Б — без хостинга, за одну минуту

Файл `standalone.html` — это всё приложение целиком в одном файле.

1. Положите `standalone.html` в iCloud Drive (он уже там).
2. На iPhone: «Файлы» → найдите файл → откроется в Safari.
3. Работает всё, кроме иконки на домашнем экране.

Минус: Safari при открытии из «Файлов» может со временем очистить
локальное хранилище, и прогресс потеряется. Для постоянных занятий
лучше вариант А.

### Вариант В — на Mac

Просто откройте `index.html` в браузере. Или, чтобы работал офлайн-режим:

```bash
cd "путь/к/папке/English"
python3 -m http.server 8000
```

Дальше `http://localhost:8000`. С Mac этот же адрес открывается
и с телефона по Wi-Fi — замените `localhost` на IP-адрес Mac.

## Как заниматься

Метод Петрова держится на регулярности, а не на длительности.
**15 минут каждый день лучше, чем два часа в субботу.**

Рабочий цикл на один урок:

1. **Теория** — прочитать один раз. Не заучивать, просто понять схему.
2. **Тренажёр** — 2–3 подхода по 15 фраз. Держите таблицу перед глазами
   первые разы, потом убирайте.
3. **Слова** — карточки каждый день, даже в дни без нового урока.
4. **Экзамен** — когда фразы начали выскакивать без раздумий.

Не спешите открывать следующий урок. Первые три — фундамент всего
остального, на них не жалко потратить неделю.

## Структура проекта

```
index.html          точка входа
standalone.html     то же самое одним файлом (генерируется build.py)
manifest.json       описание PWA
sw.js               офлайн-кэш
icon.svg            иконка
css/app.css         стили
js/data.js          глаголы, местоимения, морфологические данные
js/course.js        16 уроков: теория, словари, настройки тренажёра
js/engine.js        генератор фраз (базовая таблица, to be, модальные,
                    Continuous, Perfect, there is, повелительное, пассив)
js/app.js           интерфейс, профили, SRS, прогресс
build.py            сборка standalone.html и PNG-иконок
test.js             проверка движка (8000 сгенерированных фраз)
test-ui.js          сквозной прогон интерфейса
```

## Разработка

```bash
python3 build.py        # пересобрать standalone.html после правок
node test.js            # проверить генератор фраз
npm i jsdom             # один раз, для теста интерфейса
node test-ui.js         # прогнать весь пользовательский сценарий
```

**Важно:** после любой правки в `js/` или `css/` нужно запустить
`python3 build.py`, иначе `standalone.html` останется старым.

### Добавить глагол

В `js/data.js`, в массив `VERBS`:

```js
{ en:'swim', p2:'swam', p3:'swum', L:9,
  ru:{ inf:'плавать',
       pres:['плаваю','плаваешь','плавает','плавает','плаваем','плавают'],
       pm:'плавал', pf:'плавала', pp:'плавали' },
  o:[['','' ],['well','хорошо'],['every day','каждый день']] }
```

`L` — с какого урока глагол появляется в тренажёре.
`p2: null` — правильный глагол, форма посчитается сама.

### Добавить слова в урок

В `js/course.js`, в массив `vocab` нужного урока: `['word', 'перевод']`.
Слово автоматически попадёт в карточки.
